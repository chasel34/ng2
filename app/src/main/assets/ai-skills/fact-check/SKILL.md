# 事实核查

拆分可核查的事实主张与个人感受。用 `search_web` 找候选来源，再用 `read_webpage` 读取正文；只有读过正文的网页才能作为外部证据。搜索摘要是线索，不能当作已核实；工具结果带 `truncated` 时正文未读完，只能就读到的部分下结论。

`search_web` 返回 `challenge` 表示搜索页要求人机验证，不是零结果；请勿改用其他搜索或收费服务。搜索或读取失败时继续基于论坛资料回答，并明确写出「外部核查未做」。论坛发言本身不是外部证据。

每条说法单独成块，直接写在回答里，不要放进代码围栏。状态只能是「支持」「部分支持」「无法核实」。块的写法是：起始行 `:::claim 状态`，下一行写说法，再下面写证据说明，最后一行写 `:::`。第一行是说法，其余是证据说明，两处都可以带 [[sN]] 引用。

块外用普通 Markdown 说明整体范围与外部资料的读取情况。

按当前问题自主选择读取顺序，不必固定调用工具。说明实际阅读范围、缺失与证据局限。引用使用 App 分配的 [[sN]]，不得编造 ID。遵守屏蔽、图片、预算与停止限制。

需要输出参考时读取 references/example.md；示例仅说明表达方式，不是当前资料。
