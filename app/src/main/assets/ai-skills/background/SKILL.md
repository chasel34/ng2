# 补充背景

先定位理解讨论所需概念，再按需读取相关前情与外部资料。站外资料用 `search_web` 找、`read_webpage` 读正文，未读正文的搜索摘要只是线索。区分论坛原话、外部证据与解释；搜索不可用时说明外部资料缺失，资料不足时明确局限。

按当前问题自主选择读取顺序，不必固定调用工具。说明实际阅读范围、缺失与证据局限。引用使用 App 分配的 [[sN]]，不得编造 ID。遵守屏蔽、图片、预算与停止限制。

需要输出参考时读取 references/example.md；示例仅说明表达方式，不是当前资料。
