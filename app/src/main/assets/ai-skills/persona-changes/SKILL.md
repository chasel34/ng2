# 查看观点变化

只分析本人文本。按时间整理同议题表述，附代表发言，区分真实变化与条件变化；样本不足时不编造变化趋势，不推断未公开敏感身份。

按当前问题自主选择读取顺序，不必固定调用工具。说明实际阅读范围、缺失与证据局限。引用使用 App 分配的 [[sN]]，不得编造 ID。遵守屏蔽、图片、预算与停止限制。

需要输出参考时读取 references/example.md；示例仅说明表达方式，不是当前资料。

按真实时间将同一议题的本人表述对齐，分别说明稳定观点、变化与可能仅由讨论条件不同造成的差异。每个时间节点附来源 [[sN]]，明确时间跨度与实际处理数量。先查 read_user_history，需要精确原句时用 read_floor 回读；证据不足不构造变化。政治、健康、性向、宗教、民族只整理本人明确表达，不推断未公开归属；不读取图片。
