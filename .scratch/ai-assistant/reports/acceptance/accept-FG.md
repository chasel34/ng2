## 逐项结论

1. **F1 · 版块列表顶栏 AI → 列表概览 —— 通过**（除上面那条「已读 N 条」P3）。面板标题「列表概览 · 网事杂谈 · 最新回复」。阅读范围卡：`当前列表 / 最新回复`（已加载 36 个主题、计入 靠前 36 个、排序与筛选 保持不变）、`主题摘要 36 个`、`屏蔽规则 0 个 未计入`，下方说明「正文和楼层不默认读取，agent 按问题再读，受限速和额度约束。」，与票 10 一致。快捷操作为「深入某个话题 / 梳理讨论分歧 / 补充背景」。回答中的引用标签显示为「主题」，点击后预览为「论坛原文 / 序号 1 / 刚刚重新读取 / 0 楼 · gerraerd / 115 字 / BBCode 正文 / <标题> · 第 1 页 / 返回对话 / 跳到主楼」，确实是按当前账号重新读取的主楼预览。证据 `f-list-scope.png`。

2. **F2 · 主题行右侧 AI → 单条主题分析 —— 通过**。点 ✦ 只开面板、不跳进主题。面板标题「主题 · 我目前看到的被ai一脚踢死的职业」，范围卡为「第 1 页 20 楼 / 热门回复 0 条 / 图片 0 张」，底部「已读 20 条 · 屏蔽 0 条未计入」，快捷操作与主题详情相同（事实核查 / 批判性思考 / 梳理分歧 / 补充背景）。
   注：第一次在另一主题上尝试时得到「内容读取失败 / 内容未读取完成，已保留输入与可用资料，尚未请求模型」，同一时刻普通阅读该主题也报「服务端返回 HTTP 200，第三方客户端被拦」，属于 NGA 限流而非 App 缺陷；等待后换主题重试即通过。该次失败的状态卡上没有「重试」按钮，只能重新发起。

3. **F3 · 回复链视图 AI —— 通过**。入口是楼层引用块里的「查看对话链(4 层)」→ 回复链页顶栏 ✦。面板标题「回复链 · 4 层 · 从 5 楼展开」。范围卡：`主楼正文`、`回复链 4 层`（上游 1 楼 / 当前 5 楼 / 下游 6 楼、9 楼）、`图片 0 / 1 张`，确认只含链内楼层，没有混入第一页其他楼层。快捷操作为「梳理分歧 / 检查各方论证 / 事实核查」。图片与「1 楼」歧义两条见上面的 P3。
   另：模型用原始图片 URL 当 `imageId` 调 `read_image`，工具行按失败标红并给出「未知图片，请先列出图片」，随后自动改调 `list_images`，与 docs「读图工具只接受实际资料中的 imageId」一致。

4. **F4 · 楼层入口快捷操作 —— 通过**。楼层下方「✦ AI」打开的面板标题为「单个楼层 · 5 楼」，快捷操作为「事实核查 / 批判性思考 / 查找前情」。

5. **F5 · 历史页分类 —— 通过**（标签顺序一条 P3）。计数为 全部 25 / 主题 17 / 楼层 6 / 回复链 1 / 个人 0 / 列表 1，分项之和等于全部。逐个点开筛选：「列表」只出「列表概览 · 网事杂谈 · 最新回复」，「回复链」只出「回复链 · 4 层 · 从 5 楼展开」，「楼层」条目标题为「单个楼层 · 5 楼」，四个入口各自落到正确分类。副标题里的范围摘要也按入口不同（列表是「当前列表 · 最新回复 · 主题摘要 · 36 个 · 屏蔽规则 · 0 个」，回复链是「主楼正文 · 1 楼 · 回复链 · 4 层 · 图片 · 0 / 1 张」）。

6. **F6 · 个人分析 —— 入口与范围卡通过，报告正文未验证（P1 阻塞）**。
   - 入口：非匿名作者资料页有「✦ AI 分析发言」；匿名楼层的作者名不可点击，进不去资料页，因而没有个人分析路径。
   - 范围卡（北方向北方）：`历史回复 11 条`、`历史主题 6 个（仅标题）`、`合计 17 / 300 条`（时间跨度 2021-11-01 至 2026-09-13、顺序 从近到远、去重 按独立发言、样本正文 N 字、首轮内联 全部内联）、`屏蔽规则 0 条 未计入`、`匿名或无权限 47 条 未计入`、`图片 不读取 · 本期仅文本`。票 11 要求的各行齐全。
   - 三条快捷操作为「查看倾向依据 / 查找相反表述 / 查看观点变化」，正确。
   - 报告全屏：只在零样本那一轮拿到骨架（已处理 0 条 · 未处理 0 条 → 「只整理本人明确表达过的内容」→ 兴趣与偏好 / 议题立场 / 判断侧重 / 稳定性与变化 → 边界声明「只整理本人明确表达过的内容；不推断政治、健康、性向、宗教、民族等未公开身份或归属。结论限于已处理样本，不代表完整历史。引用他人、反讽与不同讨论条件……」）。分节与边界声明都在，但因为没有证据，倾向卡本体一张都没渲染。
