## 问题清单

- [P1] `maxAgentIterations` 被设成 8，工具调用稍多的分析必定以「回答生成中断」结束，费用照付。复现步骤：任意入口发起一次需要 4 次以上工具调用的分析（主题顶栏「批判性思考」、带图主题的顶栏概览、任意「事实核查」快捷操作）。本轮 11 次分析里 4 次中招，全部命中同一异常。证据（`adb logcat`，三次独立复现，一次日志片段）：
  ```
  ERROR ai.koog.agents.core.agent.entity.AIAgentSubgraphBase - Max iterations limit (8) reached [streaming-chat, streaming-chat, 69015b47-…]
  ai.koog.agents.core.agent.exception.AIAgentMaxNumberOfIterationsReachedException:
    AI Agent has run into a problem: Agent couldn't finish in given number of steps (8).
    Please, consider increasing `maxAgentIterations` value in agent's configuration
  ```
  两种表现：
  1. **答案已写完但仍被标为中断**。`ai_run` 为 `failed / 生成回答`，`ai_message.payload.status=回答生成中断`、`incomplete=true`、`card=INTERRUPTED`，而同一 run 在 `ai_budget` 里 4 个请求全部 `settled`（最后一次 `output=2683`），落库 `text` 长 2576 字、结尾是完整的「## 五、局限 … 不构成对该主题或其结论的整体判断。」。用户看到一份完好的回答被扣上红色错误卡和「继续」按钮，点「继续」会再花一次钱。
  2. **答案完全为空**。「事实核查」快捷操作 2/2 必中：3 次技能文件读取 + 2 次 `search_web` 就把 8 步用光，`payload` 里根本没有 `text` 字段，界面只有错误卡；点「继续」得到「内容读取失败 / 内容未读取完成，已保留输入与可用资料，尚未请求模型」，该轮永久不可恢复。即**票 06 的「事实核查」快捷操作当前完全不可用**。
  期望：票 04「回答以流式 Markdown 逐步显示」并正常结束；docs/ai-assistant.md「回答生成中断（保留文字与 N 条来源）」只应用于真的被打断的运行。建议把迭代上限提到足够容纳「技能读取 + 论坛工具 + 联网工具 + 收尾」的量级，并把 `AIAgentMaxNumberOfIterationsReachedException` 与真正的流中断区分开：已经拿到完整回答时不应标 INTERRUPTED。证据截图 `d-web1.png`（空回答 + 错误卡）。

- 「停止 → 保留文字 → 已停止 → 重新生成」仍未验证：本轮回答太快 + P1 抢先中断，没抓到可停的窗口。
