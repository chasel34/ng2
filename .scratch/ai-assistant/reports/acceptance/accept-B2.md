1. **顶栏 AI → 概览 —— 部分通过**。半屏面板升起、阅读范围卡逐项打勾（`✓ 第 1 页 19 楼` / `✓ 热门回复 3 条` / `✓ 图片 0 张` / `已读 19 条 · 屏蔽 0 条未计入`）、流式 Markdown 逐步显示（标题、有序列表、加粗、表格都正确渲染）、思考态文案已修好为「正在思考 · N 秒」→「✓ 已思考 N 秒」、行内来源标签渲染为「22 楼」「27 楼」「39 楼」胶囊、页脚「3 个来源」展开为「22 · 22 楼 · 沃斯·雷风」列表。**但正文尾部必被打乱截断（P1）**。
2. **来源标签 → 原文预览 → 跳楼高亮 —— 部分通过**。点标签或页脚来源都能打开预览，显示「刚刚重新读取」、来源序号、作者、字数、BBCode 正文。点跳转后面板收起为胶囊（从主题入口打开时）并正确定位到目标发言，目标楼层有明显高亮底色（`b2-hl.png`，约 4 秒后消失）。**但预览的楼层/页码/按钮名错（P2）**。从历史进入的会话点跳转会整个关闭面板而不是留下胶囊，与从主题入口进入的行为不一致，属可接受差异但记录在此。
