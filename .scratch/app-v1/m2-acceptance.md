## 遗留小缺陷

1. **主题列表标题 HTML 实体未解码**:精华区标题出现 `&#39;`、搜索结果标题出现 `&lt;第六感&gt;`。同一渲染路径(topic-row 标题),建议在 parseTopicList 或标题渲染处补实体解码。

   **已修**(2026-08-08)。根因:服务端不只对正文转义,`subject` 也一起转义了,而正文走 BBCode 解析时才反转义,标题不经过那条路径。修法:`core/api/fields.ts` 加 `text()`(= `str()` + `core/bbcode` 那套两轮解码,emoji 的代理对实体一并还原),`parseTopicList` 与 `parseTopicDetail`(主题标题 + 楼层标题)的 `subject` 都换成它。所有主题行(版块列表 / 搜索 / 精华区 / 热帖 / 某人的主题与回复 / 收藏夹)共用 `parseTopicList`,一处修全部覆盖。单测钉了 `&lt;第六感&gt;`、`&#39;` 两个真实标题和双重转义的 emoji。

2. **版头 0 楼顶部图片「图片加载失败」**(网事杂谈 fid -7):正文其余渲染正常,疑似 attachments 前缀或防盗链问题,待抓 URL 对拍。

   **已修**(2026-08-08)。根因不是防盗链,是**老域名**:版头帖(tid=3593852,2010 年发)正文里那张图写的是绝对地址 `https://img.nga.178.com/attachments/mon_202006/03/-914q0Q5-7r39K17T1kSdr-4w.png`,而 `img.nga.178.com` 已经停了(实测 TLS 握手直接失败);同一条路径挂在响应 `_ATTACH_BASE_VIEW` 给的 `img.nga.cn/attachments` 下是 200。之前 `attachmentUrl` 对绝对地址一律原样返回,所以拿着死域名去取图。修法:`core/api/attachments.ts` 加 `rehostLegacyAttachment`——绝对地址只要落在 NGA 自己的 `/attachments/` 目录里(域名按 `nga.cn` / `ngacn.cc` / `nga.178.com` 后缀**认**),就换成响应给的基址再拼;站外图床原样返回。目标域名仍然只从响应来,没有硬编码(ADR-0002)。fixture `read-board-head.gbk.bin` 是当天抓的真实响应,单测从响应一路走到最终地址。

3. **搜主题结果混入「帐号权限不足」行**(无作者、0 回复):服务端提示行被当主题解析,建议过滤。

   **已修**(2026-08-08)。根因:服务端把拒绝理由塞进 `subject` 当成一条主题下发,实测三种文案(「帐号权限不足」「帐号声望不足」「帖子发布或回复时间超过限制」),占比不低——搜「第六感」34 条里有 10 条、搜「炉石」34 条里有 4 条。修法:`fetchTopicSearch` 出口按**结构**过滤(`denied:"1"` + `author` 空串 + `authorid` 0),不匹配文案。只在搜索里滤:同样的行在「我的回复」「收藏夹」里是「你回过/收藏过的帖子过期了」,要照常出一行,单测把这条边界也钉住了。`totalRows` 不动(那是服务端的命中总数,翻页判据跟它对齐)。

4. (顺带观察)0 楼「支持 +1」成功后重进,操作条 👍 计数仍为 0——未确认是服务端主楼计数口径还是客户端未取到,待对拍。

   **对拍结论:服务端与客户端解析都是对的,复现不了,留待真机复验。**(2026-08-08,真实请求对拍)主楼的赞数就是 `__R[0].score`(不是 `recommend`——那个是加精数,与 `__T.recommend` 同值)。对一个 score=0 的帖子发 `topic_recommend`(pid=0)后立刻重拉 `read.php`:服务端 `score` 当场变 1,`fetchTopicDetail` 解出来的 `floors[0].score` 也是 1,撤销后回到 0;另取三个热帖,主楼 score 分别是 17 / 270 / 175,字段本身没问题。唯一能复现「点了还是 0」的是**锁帖**:版头帖(locked)发赞会被服务端回「不能支持或反对这个帖子」,score 恒为 0——但那种情况 UI 会吐错误 toast 而不是「已支持 +1」。剩下的可能是重进时 React Query 先把缓存里的旧页面(score=0)上屏、后台 refetch 还没落地就被看到了。**复验方法**:点赞后退出再进,停留 2 秒看数字是否自己跳成 1;若一直是 0,再看是不是锁帖。
