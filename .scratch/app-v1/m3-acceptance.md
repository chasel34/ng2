## 缺陷

1. **24 https 链接系统分发不被 app 接住(App Links 授权缺失)**。`am start -a VIEW -d "https://bbs.nga.cn/read.php?tid=…"` 不弹选择器,直接进默认浏览器;`ngabbs.com` 同。诊断:intent-filter 声明完整(http/https + BROWSABLE,覆盖 bbs.nga.cn / ngabbs.com / bbs.ngacn.cc / nga.178.com / nga.donews.com 五域名),`pm query-activities` 里本 app 在候选中;但 `pm get-app-links` 显示五域名全部 `Selection state: Disabled`——Android 12+ 对未验证且未获用户授权的 web link 直接交给默认浏览器。显式投递时 app 路由正确,**不是解析/路由 bug**。取舍待定:`autoVerify` 需要域名侧 assetlinks.json(NGA 域名不归我们控制,自动验证必然失败),现实选项是 app 内引导用户到系统设置手动开「打开支持的链接」,或接受现状(官方公告条「建议登录多个账号,可有效改善跳转系统浏览器的问题」暗示官方 app 也面临同类问题)。
2. **18 错误页 server explanation 渲染原始 HTML**:51 待审核页的说明区逐字显示 `51:帖子正等待审核;<br/><a href='/nuke.php?…' style='color:dimgray' …>[查看所需的权限/条件]</a>`,标签属性裸露约 5 行。应剥标签(或至少把 `<br/>` 转行、`<a>` 取文本)。
3. **首页「我的收藏」tab 错误态显示裸异常**:断网时该 tab 显示 `fetch failed: java.io.IOException: unexpected end of stream on https://ngabbs.com/...` + 重试按钮,无友好文案,与详情页错误页规格不一致。应换成统一的友好错误组件。
4. **「由 URL 读取」错误提示不随输入清除**(低):报红「只认 NGA 官方域名的链接」后清空重输,红字保留到再次点「打开」才刷新。建议 onChangeText 清错误态。

5. **(体验,待定性)自己资料页入口隐蔽**:抽屉头像/昵称行与「账号管理」内卡片均进账号管理,唯一资料页入口在「我的主题」右上角人形图标。若设计意图是头像进资料页则为路由指向不符,否则建议补一个显性入口。

## 非缺陷 / 定性结论

- **主楼点赞计数「归零」= read.php `score` 服务端滞后**:app 点赞已入账(再次调 `topic_recommend` 返回「你取消了对这个帖子的支持」),但同刻 `read.php` 的 floor0 `score` 仍返回 0。客户端解析与提交都正确,M2 遗留第 4 项就此关闭。
- **子版块 chips 不消费屏蔽状态 = 设计如此**:CONTEXT.md 定义子版块屏蔽的作用面是「其主题」(服务端 block_tids 表过滤父版块主题列表),chips 是全量导航入口。屏蔽后主题列表的过滤效果因当时列表无「篮球」帖样本未能取证。
- 19 三项已知缺口(投票模块反解不出、嵌套 from_client 空、匿名楼主翻页丢楼主标记)维持票面「不算缺陷」。
- Expo dev 齿轮悬浮球遮挡右下角控件(FAB 右半、保存按钮角、下一屏按钮)——dev 包调试件,非产品缺陷,但验收时需避让。

## Comments(方法学)

- 断网模拟:HyperOS 上私有 DNS 置无效域、`cmd connectivity set-package-networking-enabled` 均不生效(连接池 + ROM 回退)。最终方案:Mac 端过滤代理(仅放行 localhost 隧道保 Metro,余下全拒)+ `settings put global http_proxy <mac>:8899` + `am force-stop` 清连接池。代理拒绝日志顺带成了域名轮换的证据。
- GUI 操作由子代理驱动(截图消耗隔离在子上下文),服务端状态一律 Mac 脚本对拍(`get/set_block_word`、`check_in`、`ucp get` 读签名、`topic_recommend`),比纯 GUI 验收省一个数量级 token。
- 官方关键词互通用 ASCII 测试词(adb 无法输中文;网页版人工核对改为 API 对拍,数据是同一份)。中文词的 GBK 写入链路由单测钉住,真机侧有本地规则「相亲」(T9 输入)侧证中文处理。
- 测试残留已全部清理:本地规则(相亲、屏蔽此人残留)删除、官方屏蔽表回读为空、签名清空(读回空串)、阅读时常亮恢复关、全局代理 `:0`、私有 DNS off。当日签到是真实签到,无法撤销。
