## J. 回归(改动面广,过一遍主链路)

顶栏按钮尺寸、空态组件、动效常量是**全局改动**,受影响的屏比票面列的多。
以下按最短路径走一遍,只看「有没有被改坏」:

首页 → 版块列表 → 帖子详情(翻页 / 楼层菜单 / 点赞 / 收藏)→ 大图查看器 → 回复链
→ 用户资料 → 我的主题 → 搜索 → 通知 → 收藏夹 → 我的缓存 → 浏览历史 → 屏蔽规则
→ 设置三屏 → 字号调节 → 关于 → 网页兜底页。

每屏只确认:顶栏没错位、没有豆腐块图标、返回键正常、空/失败态不裸报错。
