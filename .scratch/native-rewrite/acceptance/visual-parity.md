# 视觉一致性对照:Expo 版 vs 原生版

- 设备:Pixel_8 AVD `emulator-5554`,1080x2400,420dpi(density 2.625,1dp = 2.625px)
- 左 = Expo 版 `com.chasel.ng2`,versionName 0.1.0,`lastUpdateTime=2026-08-13 01:39`
- 右 = 原生版 `com.chasel.ng2.n`,versionName 0.1.0,`lastUpdateTime=2026-08-23 20:13`(HEAD,已登录 lemon43)
- 对照图:`visual/<NN-screen>.png`,50% 缩放并排,左蓝标 / 右橙标
- 主对照在**日间**(`cmd uimode night no`);夜间抽 3 屏另列一节。收工恢复 `auto`。

## ⚠️ 先说一个影响全篇判读的前提:Expo 包比 RN 源码 HEAD 旧 8 天

装在机上的 Expo release 打于 **2026-08-13**,对应 RN 源码大约 `5f445d5`(08-14)之前。
它之后 RN 侧还有三个改 UI 的提交,**原生版是照 HEAD 移植的**:

| 提交 | 日期 | 改了什么(与本次对照直接相关) |
|---|---|---|
| `2055317` | 08-15 | 全列表迁移 LegendList |
| `0317aee` | 08-19 | 横滑翻页,页码/tab 松手同步 |
| `ccf4ecd` | 08-21 | 「UI 打磨一轮」:首页顶栏应用名 `NGA 阅读器`→`NG2`、**删首页 kebab(⋮)并把条目并进抽屉**、抽屉补「收藏夹」「短消息」、收藏宫格改用分类树里的真实版块图标、「上次读到第 N 楼」改浮层、菜单分组留白换 hairline、帖子列表 meta 行对齐、长图加渐隐角标、楼层菜单删「支持/反对」 |

所以本篇每条差异都标三种归属之一:

- **原生偏离** —— 原生与 RN 源码 HEAD 不符,是缺陷,开票。
- **Expo 包过时** —— 原生与 HEAD 一致,是 Expo 这个旧包落后了。**不开票**,但所有者若以「机上这个 Expo 包」为准,需要知道差在哪。
- **状态差异** —— 登录态 / 本地数据 / 已关闭公告之类,不是渲染问题。
