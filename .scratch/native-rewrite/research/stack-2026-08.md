# 2026-08 技术栈核实(探查归档)

> 探查 agent 报告,取数日 2026-08-21。版本号全部来自 Google Maven / Maven Central 的 maven-metadata.xml 或 GitHub Releases API 当天实查(search.maven.org 索引严重滞后,勿用)。最终决定见 ADR-0004。

## 逐项核实表

| # | 项目 | 最新 stable | 对本项目 |
|---|---|---|---|
| 1 | Kotlin | **2.4.10**(2.4.0=2026-06;K2 唯一编译器,K1 退场;context parameters stable) | 用 2.4.10 |
| 2 | AGP+Gradle | **AGP 9.3.1 + Gradle 9.7.1**(8.x 退场;AGP 9.3 要求 Gradle ≥9.5、JDK 17) | 9.3 的 optimization DSL(R8+资源收缩)、`keepRules/` 源集、`analyzeReleaseR8Config` |
| 3 | Compose | **BOM 2026.08.00** = core 1.12.0 / material3 1.4.0;**要求 compileSdk 37 + AGP ≥9.1.1** | 性能时间线全进 stable:1.9 CacheWindow 预取、ARR modifier → **1.10(2025-12)pausable composition 默认启用、官方口径滚动追平 View** → 1.12 TTID 追平 View、keyed SideEffect |
| 4 | 导航 | **Navigation 3 = 1.1.6**(1.0=2025-11-19,官方「stable and recommended」) | Nav3 runtime+ui + `lifecycle-viewmodel-navigation3:2.11.0`;NavDisplay 自带 predictive back 动画 |
| 5 | DI | **Hilt 2.60.1**(活跃) | 用 Hilt(KSP)。Metro 1.4.2 才 stable 四个月观望;Koin 运行时解析与冷启取向不合 |
| 6 | 网络 | **OkHttp 5.5.0**;Retrofit 3.0.0 但 2025-05 起零发版;Ktor 3.5.2(KMP 取向) | **裸 OkHttp + okhttp-coroutines,不上 Retrofit**:拦截器链/`newBuilder()` 派生 client 独立连接池/字节级 body+GB18030/CookieJar 全是 OkHttp 原生能力 |
| 7 | 序列化 | **kotlinx.serialization 1.11.0** | 够用不需要 Moshi:`ignoreUnknownKeys`+`isLenient`+`coerceInputValues` 打底;对象/数组二象性用 `JsonTransformingSerializer`;按内容分派 `JsonContentPolymorphicSerializer`;最脏端点 `JsonElement` 树兜底;1.11 的 `JsonDecodingException` 带 path/offset |
| 8 | 图片 | **Coil 3.5.0** | `coil-compose`+`coil-network-okhttp`(复用同一 OkHttpClient,帖内图自动带 Cookie/UA) |
| 9 | 存储 | **Room 2.8.4 + DataStore 1.2.1** | Room 用 KSP+`androidx.room` 插件(coroutines/Flow 已并入 runtime,无需 room-ktx);SQLDelight 不换 |
| 10 | 性能工具 | **benchmark/baselineprofile 1.4.1**(1.5.0-rc01 在门口) | `androidx.baselineprofile` 插件 + `benchmark-macro-junit4` + `profileinstaller` + uiautomator 2.4.0;minSdk 31 正好够 frameOverrunMs 判据;1.5 转正后再升 |
| 11 | targetSdk 36 行为 | — | edge-to-edge opt-out 失效(新写 Compose 无痛);**predictive back 默认开**(onBackPressed/KEYCODE_BACK 不再回调,Nav3 已适配);16KB page size 与纯 Kotlin 无 NDK 无关(引入带 .so 的三方库时注意);compileSdk 用 37 |
| 12 | Compose@120Hz 工法 | — | ① release+R8+**Baseline/Startup Profile**(最大头);② BOM ≥2025.12 吃 pausable composition;③ lazy 列表 key/contentType+CacheWindow;④ strong skipping 已默认,配 kotlinx-collections-immutable、状态读取下沉 lambda/graphicsLayer;⑤ ARR:`Modifier.preferredFrameRate`(旧名 requestedFrameRate)滚动面投 120、静态页投低档;⑥ 验证用 composition tracing+Macrobenchmark frameOverrun,**勿在 debug 包/AVD 判卡顿** |
