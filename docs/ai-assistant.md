# 主题 AI 助手

在主题详情顶栏点击 AI 图标，或点击楼层下方的 AI，打开阅读与对话面板。首次使用需要在「设置 → AI 助手」保存 DeepSeek API Key；没有 Key 时只显示设置入口，不读取论坛资料或请求模型。

主题概览读取第一页、热门回复和打开面板时的当前页，第一页不重复读取。当前页保留「只看某用户」或「只看某楼层」的筛选条件，筛选第一页与普通第一页分别读取并按发言去重。单楼概览按选中 pid 定位，只带入主楼与选中发言；未找到目标时标为未读取，不发起模型请求。实际阅读范围、屏蔽数量与图片数量显示在面板中，范围卡里的条数是本次准备范围，不随后续工具续读增长；本地规则和官方屏蔽规则均在发送前应用，无法取得官方规则时停止分析。匿名作者统一为「匿名用户」，不发送本地生成的假名。

首次最多带一张图片：主题优先主楼第一张，否则按当前页楼层原始顺序取第一张，热门回复顺序不影响选择；单楼只取选中发言的第一张。图片读取独立于论坛阅读的 Wi-Fi 图片设置，下载限制为 12 MiB，解码采样至边长不超过约 2048 像素，通过 Koog 二进制图像消息发送。图片失败不静默删除图片后继续，界面保留对话并允许重试。视频和非图片附件只保留链接。

面板支持半屏、全屏和收起胶囊。以设计稿 844 高度为基准，半屏顶部为 332；拖动松手顶部小于 170 吸附全屏，大于 560 收起，其余回半屏，按可用高度同比例适配。按钮可直接切换，点击胶囊回半屏。收起继续运行；停止会取消当前读取与模型流，保留草稿并标记未完成。继续与追问创建新运行；继续从最近完整检查点恢复，不自动重放中断请求。

回答使用原生 Compose Markdown；围栏内的标题、列表、引用前缀以及行内代码中的强调、链接都按字面显示，仅来源标记继续校验。停止或中断保留的文字会去掉末尾只有标记、没有正文的残缺行（如单独一行 `##`），未闭合围栏内的内容保持原样。论坛来源标签或每条回答页脚的来源列表点击后，先打开论坛原文预览；只有点击跳楼层才收起面板并定位，楼层完成加载后高亮四秒。站外来源改为打开站外预览。输入框可以继续同一对话，成功轮次保留完整模型消息（包括思考协议字段），停止的残缺模型消息不作为完整消息回传。返回半屏保留聊天滚动位置。回答新增文字时自动跟随底部；上翻查看较早内容时保持当前位置，手动滚回底部后恢复自动跟随。

对话自动保存在本机并全账号共享，保留至用户删除。面板标题栏「历史」、设置中的「AI 对话历史」及主题顶部的对话数量条均可进入历史页。历史按入口分类并显示计数，支持按标题、主题和用户搜索（至少两个字符），按今天、昨天、更早分组。长按或更多菜单可继续聊天、打开来源或删除；删除后 Snackbar 可撤销，用量记录保留。初始内容读取失败的对话标为「读取失败」，与进程中断的「已中断」区分。设置中可确认清空全部对话。

历史进入直接全屏；收起胶囊恢复同一对话，重新点击内容入口另建对话，同一主题的多条记录并存。任务由应用级会话管理器持有，离开页面不取消。进程结束后旧运行显示已中断及停止位置，打开历史不会调用模型；用户点继续后创建新运行，通过 Koog Persistence 恢复最近检查点并复用成功工具结果，ChatMemory 保留同一对话的完整协议历史。旧回答和部分回答保持独立，不拼接为一次从未中断的输出。

保存失败时显示「对话未能保存」，停止后续请求并保留内存草稿；先重试保存，成功后再由用户决定继续。来源只永久保留坐标、楼层／贴条定位信息、作者、时间、读取时间与哈希，旧原文可能被论坛清理，续聊引用原句时要求重新读取。工作上下文、检查点和工具结果随对话删除。金额额度在每次发送前原子预留；已确认未发送的取消或失败释放预留，已发送但缺失 usage 的请求保留待核实用量，重启后无法确认发送状态的预留也保守保留。调用使用 `deepseek-flash`，开启思考；每次请求显式下发输出上限，回答正文与思考分别估算后相加，短问答档合计 1536 token、其余 4096 token，个人分析按报告体量取正文 8192、思考 4096。输出上限与单次、每日金额额度共同生效，预留按实际下发的上限计算。

引用与渲染协议及 Koog 策略选择见 [ADR-0006](adr/0006-koog-agent-runtime.md)。

模型可自行调用 `read_topic_page`、`read_floor`、`read_reply_chain`、`list_images`、`read_image`、`search_web`、`read_webpage`。工具行显示可读的工具名与参数、进行中闪光、成功或失败状态；读取内置技能的行标出技能名与文件名。参数在收起时为一行摘要，展开后给出完整参数以及读取范围、过滤数量、缓存来源与失败明细，不重复同一段文字。模型写错框架工具名时按注册名执行；请求不存在的工具按失败标注并说明未读取资料。全部结算后显示失败次数，开始回答时自动收起，用户已操作的展开状态保留。停止同时取消排队、论坛读取和图片请求，未完成行标为已停止。

联网工具用 DuckDuckGo Lite 搜索，返回标题、链接和摘要，再由 `read_webpage` 读取有界正文。搜索走 Lite 的表单 POST，GET 查询会稳定返回人机验证页。搜索区分三种结果：有结果或零结果都是成功，`challenge` 表示搜索页要求人机验证，`request_failed` 表示网络失败；验证页不当作零结果，也不自动改用其他引擎或收费服务。单次最多返回并编号 10 条结果，超出的条数单独说明且不分配来源编号，不能引用。正文按字节与字数双重上限读取，触达任一上限时结果、工具行、来源标签与预览都标为「未读完」，不能声称已读全文。只有本轮既没有成功搜索也没有成功读取网页时，回答顶部才出现「外部搜索暂时不可用」通知条；部分搜索失败只在对应工具行标记失败，已读到的网页照常计入。网页请求走独立 HTTP 客户端，不携带任何 Cookie；URL 策略拒绝非 http(s)、带账号信息、localhost 与私网地址，重定向逐跳复检，DNS 解析到私网地址同样拒绝。站外请求最多两个并发、失败重试一次，搜索结果与网页正文在会话内短期缓存。个人分析入口不注册联网工具。

工具通过共享 TopicRepository 和 NGA READ 恢复链读取，不在外层重复重试。所有论坛工具共享串行限速器，请求发起间隔至少 800 ms；会话内复用已读页面和图片，页内楼层定位也复用页面。每次返回前应用屏蔽规则，匿名作者不含本地假名。失败分别返回 `permission_denied`（当前账号无法查看）、`unavailable`（已删除或不可访问）、`request_failed`（请求失败），参数错误返回 `invalid_parameters`，不能把失败当成空结果。同一坐标失败后本次运行不再重复请求，重复调用直接返回原因并注明未重复请求；达到执行上限后所有工具返回 `limit_reached` 且不执行。

主题页和楼层正文每次最多返回 16000 字符，以 `nextOffset` 续读；图片索引每次最多 100 项。回复链每页最多 20 个节点，读取引用上游与本范围创建时已加载页面（含热门回复）的下游，按主题与 pid 去重，明确说明没有扫描整楼；长节点保留定位坐标并提示通过楼层工具补读。每页返回 `rangeVersion` 和当前页 `cursor`；还有未读节点时返回包含 tid、pid、cursor、offset 的 `continuation` 对象，将它作为同一工具的完整参数即可续读。回复链不再返回 `nextOffset`，也不接受非零 offset；正文和图片索引仍使用各自的偏移分页。

回复链游标保存每页未读队列、已访问坐标和范围版本；本页执行完成后固定本页节点顺序与下一游标。重用游标不会重遍历旧前缀或消耗它，返回前仍按当前屏蔽规则过滤正文。后来通过其他工具加载的下游不插入旧范围：如需纳入这些新分支，不带 cursor 从原起点创建新范围，返回的范围说明也会明确提示这一点。每累计 300 个节点且仍有未读节点时标记 `rangeLimitReached`，继续使用该页 continuation；跨主题未读分支完整保留。未知游标或与原 tid/pid 不匹配的游标在读取前拒绝。上述限额是资源保护，不表示已完成覆盖。

读图工具只接受实际资料中的 `imageId`，工具结果只有状态和来源标识；实际图片在整批工具结果之后追加为带来源说明的 user 图文资料，同一成功历史中不重复追加。工具调用、结果、思考字段和图片消息一起保留为完整协议轮次。资料中的指令不改变系统任务。工具注册支持文本入口禁用读图，注册表与执行层都检查该限制。用于恢复的成功工具结果、图片工作资料和回复链游标保存在当前对话的工作上下文中，随对话删除；论坛引用表不保存这些原文。

主题面板提供「事实核查、批判性思考、梳理分歧、补充背景」，楼层面板提供「事实核查、批判性思考、查找前情」。点底部胶囊或 `/` 按钮选择，也可在输入末尾输入 `/` 后按名称前缀筛选。↑↓ 移动、Enter/Tab 选择、Esc 关闭；文字变化后可再次打开，Shift+Enter 换行，输入法组合期间不触发键盘发送。生成中快捷操作禁用。快捷操作在当前对话续聊，用户消息带闪电标记；完成回答后显示「继续问」建议。

内置十份技能文档位于 `app/src/main/assets/ai-skills/`，参考示例按需读取。启动及首次使用时释放到应用私有目录 `ai-skills/<应用版本号>-<技能版本>/`，完整释放后才删除旧版本；升级失败保留旧目录，但不使用残缺的新版本发起请求。Koog `discoverSkills` 和 `generateSkillsPrompt` 生成仅含名称、用途与定位路径的目录，正文由框架 `__read_file__` / `__list_directory__` 按需读取。Android artifact 缺少 JVMFileSystemProvider，因此通过框架 ReadOnly 接口适配私有文档；规范路径检查拒绝越界与指向目录外的符号链接，不注册写入或脚本工具。每轮消息及会话工作记录保留实际技能版本，历史续聊替换旧目录提示，旧回答保持原状。

技能方法由模型自主选择和组合，首次概览指定讨论概览；其余包含事实核查、批判性思考、梳理分歧、补充背景、查找前情、检查各方论证，以及倾向依据、相反表述、观点变化。个人分析的三个技能只在个人入口提供快捷操作。事实核查使用搜索与网页读取，区分论坛发言与外部证据：只有读过正文的网页才算外部证据，未读正文的搜索摘要与未读完的正文都不能引用为已核实；搜索或读取失败时明确说明「外部核查未做」。每条说法以卡片呈现，状态只有支持、部分支持、无法核实。内置示例为虚构评审样本，不能作为当前论坛证据。

站外来源标签用地球图标显示域名，点击打开站外预览：显示域名、网页标题、已读正文／正文未读完／仅搜索摘要，主按钮「打开网页」在浏览器打开，不重新读取正文。工具全部结束后在工具行下方显示已读网页标签，点击进入同一预览。站外来源只保留网址、标题与是否已读正文，随会话入口元数据的 `sourceWeb` 映射保存，本机不保存网页原文。

来源预览与历史引用每次只按 tid/pid 重新走 NGA READ 流程，固定当前账号，禁用主题缓存回退，不读取 Room 中的模型工作正文。成功显示「刚刚重新读取」、来源序号、作者、字数及 BBCode 正文；楼层与页码沿用会话保存的坐标，按 pid 重读单楼不会把楼层改写成 0 楼。删除或不可访问时保留旧回答和坐标，禁用跳转并将历史条目标为「来源已删除」。无权限显示「当前账号无法查看」，可进入账号管理切换后再打开引用；网络失败提供重新读取，重读成功前跳转按钮不可用并说明原因；屏蔽来源不显示正文。

预览中的图片按当前楼层原始顺序标记已带入上下文与未读取数量，读取状态随对话保存；图片张数与论坛阅读同一口径，正文内联图与图片附件一并计入、同一地址只算一次，非图片附件不计入；点击查看使用现有图片查看器，不发起模型读图，也不把查看行为记为已带入。图片查看器关闭后仍在原文预览，关闭预览保留聊天位置；打开来源后暂停回答自动滚动，手动滚回底部可恢复。个人分析历史不提供图片预览入口。历史和跨主题跳转也会高亮目标楼层。

楼层与贴条使用独立来源定位信息，随会话入口元数据的 `sourceParts` 映射保存，不保存贴条正文。贴条有 pid 时按 pid 定位；无 pid 时以作者 ID、发表时间、正文和附件地址的 SHA-256 指纹重新匹配，位置重排不改变匹配结果。无 pid 贴条编辑后无法确认是否同一条，或出现多个相同匹配时，按不可访问处理，不代用父楼或邻近贴条。精确贴条预览显示该贴条的作者、原文和图片，跳转目标仍为所属父楼。

父楼预览保留当前贴条，并分别应用当前屏蔽规则。缺少定位信息的旧引用无法区分父楼与贴条，显示「当前范围已重读」及无法确认原引用的说明，列出父楼与当前贴条范围；没有贴条时也明确说明，不把父楼仍存在当作旧贴条仍存在。旧引用不会被自动补写为父楼定位，后续保存和恢复保留未知状态。

## 额度、用量与运行状态

每次概览或追问使用一份分析额度，模型工具循环、思考及自动重试共用，发送前原子预留。暂定短问答 ¥0.2、默认 ¥0.5、长楼 ¥1、更高 ¥2；这些默认值尚未完成真实样本校准。预留按实际字符估算输入 token，不按 UTF-8 字节数计；单次额度档位同时决定输出上限、工具执行次数上限与 Koog 循环上限，短问答档为 1536 token、12 次工具、24 步循环，默认档为 4096 token、24 次工具、40 步循环；个人入口的输出上限改按报告体量取值（正文 8192、思考 4096），档位仍决定工具与循环上限。达到单次额度后保存已有结果，在对话内单选追加或结束并确认；关闭卡片只折叠为待确认。追加计入同一分析和当天用量，不能绕过设置中的每日上限。

生成中不显示费用；本轮结束后状态行附带估算费用，点开可看请求数、输入/缓存/输出 token、网页、图片和重试明细；设置中查看今日用量和每日占比，两处明细同口径，网页次数随发起该批工具调用的请求记账。金额使用带版本和日期的人民币价格表（DeepSeek 官方人民币定价），早期以美元记账的记录在启动时按官方 20:3 的固定比例换算；未知缓存按未命中，时段不确定按峰时价。已发送后取消、断线或缺失 usage 的请求保留保守预留并标待核实，跨日和重启不清除；能够确认尚未发送的失败或取消释放预留，429 以外的 4xx 被服务端明确拒绝、没有 usage，同样释放预留并按具体原因显示状态卡。清空对话也不重置用量。旧版本只有请求占位而没有 usage 的记录也以保守预留导入。费用以服务商账单为准。

执行上限与金额额度分开：达到工具执行次数上限或连续重复读取同一资料达到阈值时，本次运行不再执行任何工具，未执行的调用按上限结果回传，并在同一次运行内追加一次收尾请求，用已读资料写完结论，不需要用户先点继续；收尾之后仍然没有完整回答，或达到循环上限、生成因输出长度上限结束时，本轮才标为「达到限制」并说明具体上限，已生成文字与来源照常保留，用户可以继续；输出被截断不算「回答生成中断」。同一段资料在本次运行内读取失败后不再重复请求，重复调用直接返回上次的失败原因，并提示改用已有资料。状态卡与状态行不重复同一句说明；本轮文字因格式无效没有展示时，状态卡说明报告结构无效，不写「已保留文字」。本轮没有可展示文字时，待确认处理说明不提草稿，只写处理进度与已登记来源数。模型已经给出不含工具调用的完整回答时不标为失败，也不算中断。认证或余额问题显示「API Key 无效或余额不足」。

跨会话按顺序等待，同一会话重复点击不另起运行。等待期间不调用模型，收起面板继续执行，停止会取消当前任务与等待。认证、余额或每日额度问题可前往设置修正；返回后由用户点击“继续”复用原分析和检查点，不自动请求模型，每日额度仍重新检查。参数错误不原样重试，结果不明不自动重放。只有明确的限流/服务错误且尚未输出时，Koog 在共享额度内重试一次；超过允许的 Retry-After 等待时长则暂停。模型 HTTP 禁止底层透明重试。

## 列表与回复链入口

版块列表、24 小时热帖与精华区的顶栏 AI 按钮分析打开时的已加载列表，保留当时排序与筛选；过滤不可访问、屏蔽主题和非主题跳转行后，取靠前最多 300 个。阅读范围显示已加载数、计入数与屏蔽数，首次仅使用标题、作者、时间和回复数。列表行右侧的 AI 按钮则分析该主题第一页、热门回复和最多一张图片。列表摘要引用显示为「主题」，点击后按当前账号重新读取主楼预览；摘要不表示已经阅读正文。

回复链顶栏的 AI 按钮捕获当前链的全部节点和已加载资料，补读缺失的链内楼层与主楼；范围卡按上游、当前、下游展示，主楼行用状态词与真实楼层号，不默认带入第一页其他楼层。被屏蔽和无法读取的发言不计入已读数，分别注明；首次图片从链内发言选取，最多一张，图片总数同样只统计链内发言，主楼图片单独标注不参与首轮选取。

列表快捷操作为「深入某个话题、梳理讨论分歧、补充背景」；回复链为「梳理分歧、检查各方论证、事实核查」；楼层保留「事实核查、批判性思考、查找前情」。后续追问使用同一论坛工具循环，可以按主题坐标读取正文和更多楼层。各入口新建独立对话，收起后继续原对话；历史按「全部、列表、主题、楼层、回复链、个人」顺序分类，恢复时保留原阅读范围与快捷操作。列表用内部 tid=0 标记入口，不把它作为论坛主题读取；实际来源各自保存真实 tid。

历史中的来源坐标与范围卡仅用于展示，不作为模型已准备的资料。列表或回复链若在初始准备完成前中断，重启后又缺少已保存的工作上下文，点击继续会显示「入口范围不可恢复，请从原内容重新发起分析」，不会调用模型或把空的展示资料保存为工作上下文。已完成准备并保存的入口仍可在原对话继续。上述入口的无权限来源预览支持「切换账号」，进入账号管理后保留原对话。

## 个人发言分析

用户资料页的「AI 分析发言」新建个人会话，匿名用户不提供入口。自动分页读取该用户的主题标题和回复正文，按发言时间降序、以 pid（主楼用 tid）去重，合计取最近最多 300 条可访问文本。两类分页各取得最多 300 条候选后统一合并；每类最多 100 页，重复页或失败会明确标为历史不完整，保留成功资料。两类分页都没有取得可访问样本时按读取失败或无样本处理，显示对应状态卡并可重试，不发起模型请求，也不产生费用，不标为已完成。屏蔽内容不计入样本。单条样本正文超过 2000 字截断并注明可用 read_floor 重读；整份资料按 64000 字上限保留较新发言，超出的较早发言不纳入样本并单独计数。首轮消息只内联前 16000 字，其余由 read_user_history 一次续读取回（单页容量大于资料上限），以便在 Koog 循环上限内完成满额样本的报告。范围卡展示回复数、主题数（标注「仅标题」）、合计与时间跨度、样本正文字数与首轮内联情况、屏蔽数与匿名或无权限数（标注「未计入」）、超出长度上限的条数（标注「未纳入」），图片行为「不读取」并标注「本期仅文本」。主题正文由 agent 按需用 read_floor 补读，初始不全部补读；补读失败的主楼不重复尝试，改用该样本的主题标题作证据并说明正文未读取；论坛读取共用限速器。

个人报告全屏展示兴趣与偏好、议题立场、判断侧重、稳定性与变化。倾向卡的数量与信号依据去重后的证据数，1 条为偶尔提及、2–4 条为多次出现、5 条及以上为反复出现；这不是置信度。数量胶囊只写「N 条」，夹在卡片正文的 body 与 bodyTail 之间，技能约定两段的切分点，使拼接后仍是通顺的一句话。依据和相反表述抽屉按代表性发言列出引文、类型与日期，类型按来源的真实楼层判定：只有标题的样本为「主题标题」，pid 为 0 的主楼（含 read_floor 补读）为「主楼」，其余为「回复」，点击整行按当前账号重新读取原楼层；历史不保存原文快照。没有相反表述的卡片不显示该按钮，并在依据抽屉说明未找到不等于不存在。报告仅整理本人明确表达，不根据版块或语言风格推断政治、健康、性向、宗教、民族等未公开属性。

个人首次报告由 persona-evidence 技能约定的 JSON 结构承载，App 校验来源、已处理样本与卡片证据的一致性；不完整或未知来源的结构不展示为有效报告。证据、相反表述与时间线可以引用本会话已注册的任意来源，包括按技能要求用 `read_floor` 补读主楼得到的新来源；属于初始样本的编号仍须先列入已处理样本。倾向卡的命中条数由模型自报，超出「不少于代表性发言数、不多于已处理样本数」的范围时按代表性发言数显示，不作废整份报告。已处理数只按报告确认的初始样本 ID 计算，补读来源不计入；未处理部分保留并可继续；额度耗尽沿用原对话的追加额度确认。模型尚未提交有效报告时，界面在需要提交报告的那一轮说明处理数尚未确认，不把已读取数当作已分析数；普通追问的回答，以及尚未请求模型的读取失败与零样本状态卡下都不附这句说明，后两种卡片只提供「重试」。工具、续聊及历史恢复均关闭图片与图片索引读取。三项快捷操作为「查看倾向依据、查找相反表述、查看观点变化」。
