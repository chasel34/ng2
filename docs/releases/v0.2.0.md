## 本次更新

- 使用 Kotlin 与 Jetpack Compose 构建原生 Android 阅读体验。
- 支持多账号、收藏、搜索、通知、内容屏蔽与离线缓存。
- 新增楼层书签，支持保存阅读位置与备注。
- 完善帖子回复头的原文预览和主楼引用的回复链展示。
- 优化界面动效、页面返回、列表刷新与长图展示，修复转场白闪和弹窗显示问题。

## 安装

下载下方的 `ng2-v0.2.0.apk`，支持 Android 12 及以上版本。

正式包名为 `com.chasel.ng2`。相同签名的既有正式包可覆盖安装；请勿先卸载，以免清除本地数据。开发包与正式包的数据独立。

本版本尚未提供 App 内检查更新，请从 GitHub Release 下载。

本项目为非官方 NGA 客户端，与 NGA 官方无关联。
