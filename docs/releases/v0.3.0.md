## 本次更新

- 新增 AI 助手：在主题顶栏、楼层、版块列表、回复链和用户主页发起分析，支持半屏、全屏和收起胶囊，回答可继续追问，快捷操作提供事实核查、批判性思考、梳理分歧等。
- 使用 DeepSeek 官方接口，在「设置 → AI 助手」保存 API Key 后启用；未配置 Key 时不读取论坛资料，也不请求模型。
- 回答引用的论坛来源可预览原文并跳转到楼层；站外核查来源可打开网页。
- 对话历史保存在本机，按入口分类、支持搜索，可继续聊天或删除；进程中断后可从检查点继续。
- 费用按 DeepSeek 官方人民币定价估算，提供单次分析额度和每日额度控制，达到额度时由你决定是否追加。
- 修复流式回复时界面抖动、全屏时标题进入状态栏与挖孔区域、半屏完成后回答滚出可视区等问题；文字伪图标全部换成矢量图标。

## 安装

`0.2.1` 及以上用户可在「关于 → 检查更新」中下载并安装本版本。

也可下载 `ng2-v0.3.0.apk`，支持 Android 12 及以上版本。沿用正式包名和签名，覆盖安装保留本地数据，请勿先卸载旧版。
